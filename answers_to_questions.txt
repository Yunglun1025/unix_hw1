Question 4 (lines 65-66): "Explain how the counter is used for the labels."
   #Increase the counter used for the branch labels on line 63, above:

Answer 4:  "Sed branch-target labels must start with a letter (or a '_').
           They cannot start with a number. The $cnt number is not meant to
           replace the label (because then the label would illegally start
           with a number). Instead, $cnt is appended to the current label."

Question 7 (line 89): "What about ';' inside of '[...]'?"
89-#Note: But, to keep things simple, we won't worry about: "[;]".

Answer 7:  This is a confusion about what it means to 'not worry about'.
           The answer to that is that it means: 'msed doesn't need to consider
           cases where their is a ";" included as one of the characters inside
           of any "[...]" that might occur within some regular expression the
           user might provide within their msed program.'
           Or, to say it more simply, 'not worrying about it' means that: 'The
           TA will never test a case where their is a ";" with a "[...]". The
           user will never use such a regular expression within any msed code
           that the user provides in argv[1].'

                across several lines), then remember: sed is a programming
